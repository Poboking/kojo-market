## 内容

本包由脚手架生成以下核心面空壳（文件内只有 `;` 注释，不含活函数）。扩展名是 `.kojo`：.kojo 写法与原始 ERB 写法可以写在同一个文件里，导出或部署时会自动转译成游戏认得的 `.ERB`，工作区里始终只有 `.kojo` 这一份源。
部分面文件顶部带一份从口上库现成案例转写的注释示例（.kojo 写法，台词简化为类目占位）。

- `事件.kojo` — 事件面：剧情事件按事件编号触发的对白。
- `日常指令.kojo` — 日常面：散步、聊天等日常相处事件的台词。
- `性交指令.kojo` — 性交指令面：性交系指令（COM）时的反应台词。
- `奉仕指令.kojo` — 奉仕指令面：奉仕系指令（COM）时的反应台词。
- `爱抚指令.kojo` — 爱抚指令面：爱抚系指令（COM）时的反应台词。
- `绝顶.kojo` — 绝顶面：绝顶参数（PALAM B）达标时的台词。
- `刻印取得.kojo` — 刻印面：取得刻印或素质变化（MARKCNG）时的台词。
- `性骚扰指令.kojo` — 性骚扰指令面：触手等性骚扰系指令（COM）时的反应台词。

## 部署

编辑器的「部署到游戏目录」会把本包转译后放进游戏目录：

```
ERB/口上・メッセージ関連/個人口上/<角色口上目录>/东方口上集-博丽 灵梦 v1.0/
```

（游戏目录默认只读，需先批准写权限；目标已存在时不会覆盖。）

手工放置也可以：先把 `.kojo` 全部转译成同名 `.ERB`，再把 `.ERB` 连同辅助文件复制过去。
**直接把 `.kojo` 放进游戏目录是不生效的**——引擎只读 `.ERB`。
